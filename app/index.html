Results

Formulas used
  • Estimated total static thrust = Scaled peak 100% throttle thrust (gf) from the test data (adjusted by the voltage ratio squared) × number of motors.
  • Thrust-to-weight ratio (TWR) = Estimated total static thrust ÷ actual drone weight.
  • Max safe weight (AUW) = Estimated total static thrust ÷ minimum target TWR.
  • Max loaded RPM = The highest RPM value recorded across the motor test data rows (adjusted by the voltage ratio), replacing the previous 0.85 estimation factor.
  • Target operational RPM = Interpolated RPM value obtained from the motor test data corresponding precisely to the required thrust per motor for a given target TWR.
  • Target RPM limit check = Verifies that the target operational RPM does not exceed the max loaded RPM.
  • Total system peak current = Scaled peak 100% throttle current per motor × number of motors.
  • Minimum C-rating = Total system peak current ÷ battery capacity (Ah).
  • ESC burst rating evaluates the transient zero-airspeed spike, allowing up to a 10% excess resistive heat rate ((Peak Amps ÷ ESC Burst)² - 1).
  • Propulsion utilization = Target thrust (weight × minimum target TWR) ÷ estimated total static thrust (checked against the configured propulsion utilization limit).
  • ESC continuous capability and capping = Evaluates the exact interpolated continuous current required to hover, capped so it can never exceed the 100% peak motor current limit.
  • ESC continuous utilization = Required continuous current ÷ ESC continuous rating (checked against the configured ESC utilization limit).
