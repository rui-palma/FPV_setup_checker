Results

Formulas used
  • Estimated total static thrust = Scaled peak 100% throttle thrust from test data (adjusted by RPM ratio squared and propeller diameter ratio to the 4th power) × number of motors.
  • Thrust-to-weight ratio (TWR) = Estimated total static thrust ÷ actual drone weight.
  • Max safe weight = (Estimated total static thrust ÷ minimum target TWR) × propulsion utilization limit.
  • Max loaded RPM = Highest RPM value from motor test data, adjusted by the voltage ratio and propeller slip factor.
  • Target operational RPM = Interpolated RPM value from test data corresponding to the required thrust per motor.
  • Target RPM limit check = Verifies that target operational RPM does not exceed the theoretical no-load maximum (KV × Max Battery Voltage).
  • Total system peak current = Scaled peak 100% throttle current (adjusted by RPM ratio cubed and propeller diameter ratio to the 5th power) × number of motors.
  • Minimum C-rating = Total system peak current ÷ (battery capacity in mAh ÷ 1000).
  • ESC burst rating = Evaluates transient zero-airspeed spikes. Calculates excess heat rate as ((Peak Amps ÷ ESC Burst)² - 1) × 100, warning if >0% and critical if >15%.
  • Propulsion utilization = Target thrust (weight × minimum target TWR) ÷ estimated total static thrust.
  • ESC continuous capability = Interpolates the continuous current required to maintain target TWR, capped at the peak motor current limit.
  • ESC continuous utilization = Required continuous current ÷ ESC continuous rating.
  • Capacitor voltage margin = Checks that capacitor rated voltage exceeds maximum battery voltage (Cell count × 4.2V) with at least a 35% safety margin.
  • Minimum required capacitance = C_min = (I_ripple × ΔT) ÷ ΔV. Switching period ΔT = 1 ÷ 24000 Hz, current ripple I_ripple = 0.22 × Total Peak Amps, and allowed voltage ripple ΔV = 0.10 × Max Battery Voltage. Recommended setup provides ≥ 1.5 × C_min.
