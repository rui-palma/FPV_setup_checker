Results

Formulas used
  • Estimated total static thrust = total peak power (W) × size-dependent full-throttle efficiency factor (gf/W)
  • Thrust-to-weight ratio (TWR) = estimated total static thrust ÷ actual drone weight
  • Max safe weight (AUW) = estimated total static thrust ÷ minimum target TWR (2.0 for ≥10" props, 3.0 for smaller props)
  • Estimated loaded RPM ≈ sagged voltage × KV × 0.85
  • Peak current per motor = peak power per motor ÷ sagged voltage
  • Total system peak current = peak current per motor × number of motors
  • Minimum C-rating = total system peak current ÷ battery capacity (Ah)
  • ESC checks: Burst rating evaluates the transient zero-airspeed spike, allowing up to a 10% excess resistive heat rate ((Peak Amps ÷ ESC Burst)² - 1);
  • Continuous rating evaluates the exact interpolated continuous current ($I_{\rm required,motor}$) required to hover and maneuver at the target TWR ($R$) using formula $T_{\rm required,motor} = \frac{RW}{N}$.
